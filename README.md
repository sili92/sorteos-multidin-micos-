# 🍒 CherrieBot — Telegram Bot

Bot oficial de **Cherrys** diseñado para la gestión de dinámicas, minijuegos y entretenimiento en grupos de Telegram.

---

## 🚀 Características
- **Puntos y Logros:** Sistema de gestión de puntuaciones e hitos para usuarios.
- **Minijuegos Integrados:**
  - 🧠 *Quiz Game*: Preguntas y respuestas con niveles de dificultad.
  - ⛏️ *Minería*: Sistema de giros y turnos interactivos.
  - 🎟️ *Lotería*: Venta de tickets y selección de ganador en tiempo real.
  - 🎁 *Sorteos*: Organización de dinámicas rápidas.
- **Utilidades:** Captura de `file_id` de stickers, comandos interactivos (ej. `/beg`).

---

## 🛠️ Tecnologías
- Python 3.10+
- [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI)

---

## ⚙️ Despliegue en Railway

1. Haz un fork o clona este repositorio.
2. Crea un nuevo proyecto en [Railway](https://railway.app/).
3. Conecta este repositorio.
4. Define la siguiente **Variable de Entorno** en el panel de Railway:
   - `BOT_TOKEN`: Tu token obtenido a través de [@BotFather](https://t.me/BotFather).
